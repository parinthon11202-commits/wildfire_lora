# ทดลอง FG1 บนเครื่อง: Backend + MongoDB + Dashboard

ชุดนี้ให้เห็นการทำงานต่อกันจริงของ Backend, MongoDB, API, การลงทะเบียนกุญแจ FG1,
การตรวจแพ็กเก็ต, ประวัติ readings, เหตุการณ์ alerts และ Dashboard **บนเครื่องของคุณ**
ส่วน Node กับ Gateway ที่ส่งคลื่น LoRa ยังเป็นโปรแกรมจำลอง ไม่แฟลชบอร์ดและไม่ deploy

## วิธีเปิด

1. เปิด MongoDB บนเครื่องที่ `127.0.0.1:27017`
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน
   `powershell -ExecutionPolicy Bypass -File .\start-fg1-local.ps1`
3. เปิดหน้าให้ลองกดที่ <http://127.0.0.1:4401> และหน้า Dashboard ที่
   <http://127.0.0.1:4400>
4. เปิด MongoDB Compass → `127.0.0.1:27017` → `wildfire_fg1_local_lab` → `nodes` หรือ `readings`
5. เมื่อต้องการหยุด ให้กด Ctrl+C ใน PowerShell ที่รันโปรแกรม

ฐานนี้แยกจาก `wildfire_lora`, `wildfire_lora_local` และ `wildfire_fg1_key_demo`
โปรแกรมใช้พอร์ต 4400 กับ 4401 บน `127.0.0.1` เท่านั้น

## ดูกุญแจจริงกับค่าที่เก็บใน MongoDB

ครั้งแรกโปรแกรมจะสุ่ม `DEVICE_REGISTRY_KEY` และ `GATEWAY_API_KEY` เก็บใน
`.fg1-local/config.json` แล้วลงทะเบียน NODE01 ผ่าน API ของ Backend จริง

- กุญแจจริงของ **NODE01 จำลอง** อยู่ใน `.fg1-local/node01.json` เหมือนการเก็บในหน่วยความจำถาวรของโหนด
- ชุดกุญแจที่เตรียมไว้สำหรับ lab อยู่ใน `.fg1-local/node-credentials.json` แยกจากไฟล์ของบอร์ดจริง
- MongoDB → `wildfire_fg1_local_lab.nodes.credential_ciphertext` เก็บกุญแจเดียวกัน **แบบเข้ารหัส**
- หน้า <http://127.0.0.1:4401> มีปุ่มแสดงกุญแจจำลองและค่าที่ MongoDB เก็บให้เทียบกัน

ไฟล์ใน `.fg1-local` ถูกเพิ่มใน `.gitignore` แล้ว อย่านำกุญแจทดลองเหล่านี้ไปใช้กับบอร์ดจริง
โปรแกรมเปิดครั้งถัดไปจะใช้กุญแจเดิม ไม่สุ่มใหม่ทุกครั้งที่ส่งข้อมูล

## ลองส่งข้อมูล

หน้าเว็บทดลองมีปุ่ม **ปกติ**, **เฝ้าระวัง**, **เตือนภัย**, **ส่งพิกัด**,
**ส่งด้วยกุญแจผิด** และ **ส่งข้อมูลเดิมซ้ำ**
ข้อมูลสถานะที่เลือกจะส่งต่อทุก 15 วินาที

ขั้นตอนข้างในคือ โหนดจำลองสร้างเฟรม FG1 และเข้ารหัส → Gateway จำลองดึงกุญแจจาก
`GET /api/devices/gateway` มาตรวจ → ส่งเฟรมไป `POST /api/packets` → Backend ตรวจซ้ำ
→ MongoDB บันทึก → Dashboard แสดงผล พิกัดจำลองอยู่ใกล้ตัวเมืองเชียงใหม่

ปุ่มกุญแจผิดทำให้ Gateway จำลองปฏิเสธ และชุดทดลองจงใจส่งข้าม Gateway ไปให้ Backend
ตรวจอีกชั้นเพื่อแสดง HTTP 401 ปุ่มส่งข้อมูลเดิมซ้ำแสดง HTTP 409
ทั้งสองกรณีไม่เพิ่ม `readings`

ป้ายใน Dashboard จะบอกเสมอว่านี่เป็น **Gateway และ Node จำลอง**
ถ้าต้องการใช้บอร์ดจริง ยังต้องคอมไพล์/แฟลชเฟิร์มแวร์ Gateway กับ Node,
ตรวจบอร์ด 433 MHz และสายเซนเซอร์ แล้วตั้งค่าโหนดผ่าน USB กับ Backend local
อ่านรายละเอียดใน [คู่มือ FG1](FG1_ONBOARDING.md)
