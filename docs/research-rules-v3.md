# กฎแจ้งเตือนไฟป่ารุ่น 3: SHT31 + Sharp

โหนด NODE01/NODE02 เป็นผู้ตัดสินสถานะ Backend รับผล `st` โดยไม่คำนวณซ้ำ รุ่นกฎในแพ็กเก็ตคือ `rv:3` และ `c` เป็น **ดัชนีสถานะตามกฎ** (0/25/60/90) ไม่ใช่คะแนนถ่วงน้ำหนักหรือเปอร์เซ็นต์โอกาสเกิดไฟ

## ที่มาของเกณฑ์

- [Computers 2026, 15(2), 105](https://doi.org/10.3390/computers15020105), §3.2: อุณหภูมิ ≤35°C อยู่ใน Normal, >35–45°C อยู่ใน Surveillance, >45°C เข้า Fire ตามกฎของผู้วิจัย
- [Designs 2025, 9(4), 91](https://doi.org/10.3390/designs9040091), §3.3: อุณหภูมิ ≥30°C และความชื้นสัมพัทธ์ ≤30% เป็น 2 ใน 3 เงื่อนไข 30-30-30; อีกเงื่อนไขคือลม ≥30 km/h ซึ่งโหนดนี้ไม่มีเซนเซอร์วัด จึงตรวจได้เฉพาะคู่ T/RH
- Computers ใช้ RH ≥50% เป็นหนึ่งในเงื่อนไข Normal. ช่วง RH 30–<50% สำหรับ WATCH เป็นการออกแบบของโครงการ ไม่ใช่เงื่อนไข Fire ในบทความ
- Computers ใช้ MQ-2 raw ADC >1190/>1984 และเซนเซอร์ PM2.5 แยกต่างหาก. Sharp GP2Y1014AU0F วัดอนุภาคด้วยแสงและให้ ADC raw จึง **ไม่ใช้เลข MQ-2 หรือ PM2.5 กับ Sharp โดยตรง**

## กฎของโครงการ (เรียงจากรุนแรงลงมา)

| สถานะดิบ | เงื่อนไข |
|---|---|
| CRITICAL — สงสัยมีไฟ | Sharp อนุภาคสูงมาก **และ** (T >45°C **หรือ** T ≥30°C พร้อม RH ≤30%) |
| WARNING — ความเสี่ยงสูง | T >45°C **หรือ** (T ≥30°C พร้อม RH ≤30%) **หรือ** Sharp อนุภาคสูงผิดปกติ |
| WATCH — เฝ้าระวัง | T >35°C **หรือ** RH <50% **หรือ** Sharp อนุภาคเริ่มสูงกว่าฐาน |
| NORMAL | ไม่เข้าเงื่อนไขข้างบนและฐานควันพร้อม; จะได้ T ≤35°C, RH ≥50% และไม่มีสัญญาณอนุภาค |
| CALIBRATING / SENSOR_FAULT | ฐาน Sharp ยังไม่พร้อม / ข้อมูลเซนเซอร์ใช้ไม่ได้; หากกำลังเรียนฐานแต่พบ WARNING จากอุณหภูมิหรือความชื้นยังแจ้งเตือนตามกฎ |

กฎนี้แยกความเสี่ยงจากอากาศร้อน/แห้งออกจากการสงสัยไฟจริง `CRITICAL` ต้องมีหลักฐานอนุภาค Sharp ร่วมด้วย และยืนยัน 2 รอบต่อเนื่อง (รอบแรกส่ง `WARNING`). WATCH จากอากาศล้วนยืนยัน 2 รอบเมื่อฐานพร้อม. สถานะสูงที่เคยแจ้งจะลดเมื่อกฎดิบต่ำลงต่อเนื่อง 3 รอบ. เซนเซอร์เสียแจ้ง `SENSOR_FAULT` ทันที

## เกณฑ์ Sharp ที่ต้องสอบเทียบ

ขณะนี้ `sensor_node/config.h` และ `sensor_node_2/config.h` ตั้ง `SHARP_THRESHOLDS_CALIBRATED 0` เพราะยังไม่มีข้อมูลสอบเทียบของ NODE01/NODE02 ที่แยกอากาศสะอาด ฝุ่นที่ไม่มีไฟ และควันทดสอบได้อย่างเพียงพอ. ค่า Sharp ADC ดิบและผลต่างจากฐานยังถูกส่งเพื่อเก็บข้อมูล แต่ **ไม่ถูกจัดเป็น WATCH/ELEVATED/STRONG**; เงื่อนไขจากควันจึงไม่ทำให้ขึ้น WATCH/WARNING/CRITICAL. สถานะ WARNING ยังขึ้นได้จาก T >45°C หรือ T ≥30°C ร่วมกับ RH ≤30%. `CRITICAL` ที่ต้องมีหลักฐานอนุภาคจะยังไม่เกิดจากโค้ดชุดนี้จนกว่าจะสอบเทียบและเปิดเกณฑ์ Sharp. การเรียนฐานอัตโนมัติไม่ได้รับรองว่าอากาศนั้นปราศจากควัน จึงต้องตรวจสภาพแวดล้อมขณะเก็บข้อมูลด้วย.

ก่อนใช้ภาคสนาม ให้เก็บค่า Sharp ในอากาศสะอาด ฝุ่นที่ไม่มีไฟ และการทดลองควันที่ระยะติดตั้งจริง แล้วปรับเกณฑ์ WATCH/ELEVATED/STRONG แยกสำหรับโหนดทั้งสองหรือใช้เกณฑ์ร่วมหลังพิสูจน์ว่าการตอบสนองใกล้เคียงกัน. Sharp ไม่สามารถยืนยันว่าอนุภาคนั้นเกิดจากไฟโดยลำพัง

## การส่งผลไปปลายทาง

แพ็กเก็ตเดิมยังมี `st`, `c`, `rv`, `at`, `h`, `sm`, `sr`, `ri` และ `sh`. เพิ่ม `rf` เป็น bit mask ของหลักฐานที่โหนดพบ: 1=T>35, 2=T>45, 4=RH<50, 8=T≥30 และ RH≤30, 16=Sharp WATCH, 32=Sharp ELEVATED, 64=Sharp STRONG. ปัจจุบันเมื่อเกณฑ์ Sharp ปิดอยู่ bit 16/32/64 จะเป็น 0. คีย์ `sc:0` บอกว่ายังไม่สอบเทียบ Sharp; `sc:1` ใช้หลังใส่เกณฑ์ที่ผ่านการทดสอบแล้ว. Gateway ส่งแพ็กเก็ตต้นฉบับต่อ; Backend เก็บ `risk_flags` และ `sharp_calibrated` เพื่อแสดงผลโดยไม่เปลี่ยนสถานะ. ข้อมูล `rv:1/2` ยังคงอ่านตามกฎของรุ่นนั้น
