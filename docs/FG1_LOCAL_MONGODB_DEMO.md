# ทดลองกุญแจ FG1 กับ MongoDB ในเครื่อง

ตัวอย่างนี้ใช้ MongoDB ที่ `127.0.0.1:27017` และฐานข้อมูลแยกชื่อ `wildfire_fg1_key_demo` เท่านั้น ไม่เปลี่ยนฐานข้อมูล `wildfire_lora` หรือกุญแจของอุปกรณ์จริง โหนดและ Gateway ในการทดลองเป็นข้อมูลจำลอง แต่ใช้โค้ดลงทะเบียนและตรวจแพ็กเก็ตของ Backend จริง

## ลองทำ

เปิด PowerShell ใน `wildfire-backend` แล้วรัน:

```powershell
npm.cmd run demo:fg1-mongo
```

ผลลัพธ์จะแสดงกุญแจ **ตัวอย่าง** ของ NODE01 และค่า `credential_ciphertext` ที่ MongoDB เก็บไว้ ซึ่งมีหน้าตาไม่เหมือนกัน จากนั้นจะแสดงผลว่าแพ็กเก็ตที่ใช้กุญแจตรงกันผ่าน ส่วนกุญแจผิดและแพ็กเก็ตที่ส่งซ้ำถูกปฏิเสธ

เปิด MongoDB Compass แล้วเชื่อมต่อ `mongodb://127.0.0.1:27017` เลือกฐานข้อมูล `wildfire_fg1_key_demo`:

- `nodes`: ค้นหา `{ "node_id": "NODE01" }` เพื่อดู `credential_ciphertext`, `uplink_sequence` และค่าล่าสุด
- `readings`: ค้นหา `{ "node_id": "NODE01" }` เพื่อดูประวัติที่ผ่านการตรวจ

รันคำสั่งเดิมอีกครั้งได้ ระบบจะใช้กุญแจตัวอย่างเดิมและส่งแพ็กเก็ตลำดับใหม่ให้เห็นว่ากุญแจไม่ได้สุ่มใหม่ทุกครั้งที่ส่งข้อมูล

กุญแจตัวอย่างนี้ใช้เพื่อการเรียนรู้เท่านั้น ไม่มีบอร์ดจริงใช้กุญแจนี้ และไม่ควรนำค่าในตัวอย่างไปใช้กับระบบจริง
